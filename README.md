## 🌟 核心特色

- 🔒 **纯净账号密码登录**：采用标准 WebCrypto **PBKDF2 算法**（100,000 次加盐迭代哈希），搭配 **`HttpOnly` JWT Cookie** 边缘极速验签，无第三方复杂依赖与隐私泄露风险。
- 📦 **持物资产全生命周期管理（深度借鉴「持物 / iThings」理念）**：
  - **日均成本摊薄**：让每一笔大额消费转化为每天清晰可见的微小成本。
  - **动态全成本追踪**：支持随时为大件**追加配件、升级与维修保养支出**，记录真实总支出。
  - **质保到期监控**：实时计算保修剩余天数，直观标示「在保」或「已过保」。
  - **回本勋章体系**：自动评定 `🚀已赚翻` (<¥1/天)、`💎超值利器` (¥1~5/天)、`👍日常好物` (¥5~20/天)、`⏳回本中`。
- ❄️ **冷静期心愿单**：买大件前设定 3~30 天冷静倒计时；冷静期满后可一键**确认拔草并自动在日常记账流水扣款**，也可随时**解毒放弃**省下预算。
- 💳 **多账户动态余额**：支持微信支付、支付宝、银行储蓄卡、现金钱包、信用卡等账户，**通过动态实时计算余额，彻底杜绝数据漂移**。
- 🎫 **预付费会员卡与计次卡管理 (告别预付款糊涂账)**：
  - **储值卡与计次卡双模**：支持按面值扣款的储值卡（如理发店充2000送200）与按次数核销的计次卡（如健身私教20节、洗车10次卡）。
  - **大额开销一键转卡**：在流水中点击「设为充值卡」，自动将大额预付款转入卡包资产，并剔除日常生活日均统计。
  - **极速核销打卡与真实流水联动**：一键「-1 次」或输入消费额，不仅扣减卡内剩余，还可选择同步生成一条当天的生活开销，既不重复扣银行卡，又能精确核算当期真实生活质量。
  - **单次成本透视与到期预警**：清晰呈现单次折算成本（如“私教每次 250 元”）、卡内剩余残值、使用进度条与 30 天有效期预警。
- 🔄 **周期记账与订阅管理中心 (掌控固定支出与现金流吞吐)**：
  - **多周期灵活订阅**：全面支持按月、按年、按周、按季及自定义间隔周期（如每 3 个月），涵盖软件会员（iCloud、Spotify、ChatGPT Plus）、宽带电信、房租水电等。
  - **全自动入账与自愈双引擎**：内置 Cloudflare Workers Cron Trigger 定时任务，同时在每次进入账本时执行即时无感自愈检查，兼顾云端全自动与离线/冷启动不丢单。
  - **固定开销大盘与到期预警**：实时折算每月月均固定成本与年化总支出，提供 7 天内待续费预警与手动确认提醒，支持一键「立即入账」与一键暂停。
- 🤖 **AI 智能交互与小票记账 (Workers AI / LLM)**：
  - **自然语言/语音记账**：“昨晚海底捞花了320用微信付的”，AI 自动提取金额、匹配结算账户、归类收支分类与消费场景，一键秒级入账。
  - **小票/账单 OCR 识图**：拍照上传收据或支付截图，视觉大模型自动提取商户、实付金额、交易时间及商品摘要。
  - **AI 财务月度体检报告**：一键生成全月消费体检报告，测算财务健康得分（0~100）、趣味消费画像标签、分析跑冒滴漏并提供下月改进锦囊。
  - **免配置与全托底**：默认支持 Cloudflare Workers AI 官方免配置免费额度，支持接入 DeepSeek/OpenAI，并内置规则启发式离线托底引擎。
- 💱 **多币种与外汇钱包管理 (Multi-Currency & FX Hub)**：
  - **主流法币全覆盖**：支持人民币 (CNY)、美元 (USD)、港币 (HKD)、欧元 (EUR)、英镑 (GBP)、日元 (JPY)、新加坡元 (SGD)、澳元 (AUD)、加元 (CAD)、泰铢 (THB) 等 16+ 币种。
  - **公开实时汇率一键同步**：后端直连公开免密牌价接口，免去复杂 API 申请流程；同时支持针对个人换汇成本自由自定义微调固定折算汇率。
  - **账户原生币种与 CNY 双重透视**：账户明细清晰展示外币原生余额（如 `$1,250.00 USD`）与即时折算的人民币价值（`≈ ¥9,050.00 CNY`）。
  - **跨币种换汇转账**：源与目标币种不同时智能触发换汇面板，实收转入金额与折算汇率双向联动计算，真实反映跨币种资金流转。
  - **全币种并表净资产**：总资产、信用卡负债及个人净资产大盘统一折合为基准货币 (CNY) 汇总核算，精准反映全球综合资产净值。
- 🎯 **预算管理与超支预警 (Budget Control & Overspend Alert)**：
  - **总预算与分类子预算双层把控**：支持设定全月总支出上限，并可为餐饮美食、休闲娱乐、网络购物等大头分类单独设立专属子配额。
  - **通用基准模板与指定月自定义**：支持将预算保存为“每月默认基准”，未来新月份全自动无缝继承，也可为年节假日等特殊月份单独设定个性化限额。
  - **今日推荐可用动态测算**：根据当月剩余预算与剩余天数，实时计算 $\frac{\text{剩余预算}}{\text{剩余天数}}$，智能指导每日理性消费。
  - **三色健康进度看板**：健康绿色 (<80%)、警示黄色 (80%~100%)、超支火红 (>100%)；首页常驻紧凑微件与统计大盘深度联动，消费进度一目了然。
- ⚡️ **边缘全栈一体化**：后端基于轻量级 [Hono](https://hono.dev/) 框架，前端 SPA 通过 Cloudflare Workers Assets 原生托管，全球 CDN 毫秒级秒开。
- 💾 **数据 100% 自主可控与灾备资产中心 (Data Portability)**：
  - **全量灾备备份与一键恢复**：导出包含账户、分类、流水、大件、充值卡、周期订阅与规则的完整 JSON，换库迁移时支持智能合并或完全覆盖还原。
  - **Excel / CSV 规范报表导出**：注入 UTF-8 BOM 签名，在 Windows / Mac Office Excel、WPS 与 Apple Numbers 中打开绝无中文乱码。
  - **第三方记账软件搬家**：支持从钱迹 (Qianji)、随手记、鲨鱼记账等常见应用 CSV 一键迁移导入，自动补充缺失账户与分类。

## 📦 功能模块深度说明

### 1. 基础流水记账
- **收支与转账**：支出、收入、内部转账（例如从银行卡转入微信钱包）。
- **常用预置分类**：餐饮美食、交通出行、日常百货、休闲娱乐、住房物业、医疗健康、数码电器、服饰装扮、人情往来、工资薪酬、兼职副业、投资理财等。
- **动态账户余额**：系统在查询账户时实时对流水金额进行借贷汇总，无论修改或删除历史记录，账户余额均 100% 精确吻合。

### 2. 持物大件日均与生命周期管理（参考「持物 / iThings」）
大件物品（电脑、手机、电视、人体工学椅等）买入是一笔大开支，但通过日均计算能够极大提升生活幸福感与消费理性：
$$\text{真实日均成本} = \frac{\text{购买价格} + \text{配件与维护费用} - \text{二手转卖回血残值}}{\text{实际服役天数}}$$
- **追加配件与维护费**：支持随时为某件物品添加“购买保护壳”、“官方换电池”、“加装内存”等隐性支出，并可选择是否同步扣减钱包流水。
- **全生命周期状态**：
  - 🟢 **服役在用中**：天数每日自动增加，日均成本每日自动摊薄降低。
  - 💤 **闲置吃灰**：标记冷落物品，警示非理性消费与闲置持有成本。
  - 🔴 **已损坏/已淘汰**：输入损坏日期与原因，**锁定该物品的终身日均成本**。
  - 🟡 **已出二手**：输入卖出日期与回血金额，系统自动扣减残值重新计算持有期间的真实净支出。
- **质保到期监控**：记录保修截止日，自动计算并标示「在保 (剩余X天)」或「已过保」。
- **回本目标进度条**：设定预期寿命（如 1 年、3 年、5 年），清晰展示“已回本 85%”或“🎉 超预期服役，超值赚翻！”。

### 3. 冷静期心愿单 (抗冲动消费利器)
- 种草时不要冲动付款，先将物品加入「冷静期心愿单」，设定 3天 / 7天 / 14天 / 30天 冷静期。
- 动态倒计时展示：在冷静期内时刻提醒你保持克制。
- **已深思熟虑**：冷静期满后如果依旧心动，点击「确认买入」，选择付款账户，系统自动将物品转入服役大件，并在记账账本中生成对应的支出流水。
- **解毒放弃**：如果发现只是一时冲动，点击「🌿 解毒拔草」，即可删除心愿并为自己省下一笔大额预算。

### 4. 资产核算与可视化报表
- **净资产看板**：实时计算 `可用总储蓄资产 - 信用卡等负债`。
- **月度收支走势**：月度总收入、总支出、结余状况。
- **支出排行榜**：分类支出占比条形统计图与笔数汇总。
- **每日支出走势图**：直观反映当月每日花销高低。

### 5. 微信 / 支付宝官方对账单批量导入（智能去重）
- **官方流水支持**：直接支持微信支付 `.xlsx` / `.csv` 与支付宝 `.csv`（自动识别 GBK 与 UTF-8 编码）。
- **外部交易单号级防重**：基于平台官方交易单号严格排重，重复上传或交叉时段导入绝不会出现二次扣款或流水重复。
- **智能过滤不计收支**：自动识别并默认取消勾选“信用卡还款”、“零钱通存取”、“余额宝收益”等内部资金流转与交易关闭项。
- **智能推荐与批量归类**：按商品说明和交易对方关键词自动匹配最优账户与分类，并支持一键将同类消费批量修改为相同分类。

### 6. iOS 快捷指令「随手记账」与一键分发（多租户 & 双模式分发）
针对个人随手记账，提供极致的一秒闪电入账方案：
- **设备感知自适应引导**：
  - **iPhone / iPad**：移动端直接呈现原生 Apple 风格 **「添加到 iPhone」**（调用官方真实 iCloud 链接），并提供 **「一键激活绑定此账号」** 自动通过 `shortcuts://` 写入专属 Token，**全程零手动输入**。
  - **PC / Android**：自动渲染动态高清二维码供手机相机扫码配对，同时提供 Mac 专用的 `.shortcut` 文件直接下载。
- **双模式分发策略 (Sharing Strategy)**：
  - **模式 A（直接下载）**：接口 `GET /api/v1/shortcuts/:id/download` 直接返回已封装好接口地址与令牌的 `.shortcut` 文件，Mac 双击即可导入，支持下载统计。
  - **模式 B（官方 iCloud 分享）**：由 Apple 设备官方生成的真实分享链接持久化至 D1 数据库，杜绝虚拟链接报错，全员一键点击添加。
- **多租户数据物理隔离**：
  - 快捷指令程序本身为通用模板，系统为每个登录用户签发独立的持久 API Token（`cbk_live_...`）。
  - 用户敲击手机背面或对 Siri 语音记账时，流水 100% 写入该用户自己的账本，家庭成员共同使用绝对不串账。
  - 支持 **个人专属 iCloud 覆盖** 与 **全站官方共享** 自由切换。
- **极速触发玩法**：
  - 🗣️ **Siri 语音记账**：对手机说“嘿 Siri，随手记账”，语音说出“咖啡 18.5”自动归类入账。
  - 📱 **轻点背面两下**：在 iOS 辅助功能中将轻点背面设为「随手记账」，付款后敲击两下即弹出金额输入。
  - 📸 **截屏 OCR 识别**：付款成功后截屏分享给「随手记账」，自动解析金额与商户。

### 7. 智能规则引擎（自动分类与消费场景标记）
- **多条件灵活匹配**：支持设置包含关键词（如“星巴克,瑞幸”）、精确匹配、指定账户、交易类型等。
- **双重智能标记**：规则命中后可自动设置 **分类**（如“餐饮美食”）与 **消费场景**（如“日常三餐”、“商务出差”、“送礼社交”）。
- **一键应用历史流水**：创建或修改规则后，支持一键把规则应用到过去所有未分类的历史账单中。

### 8. 周期记账与订阅管理中心 (Recurring & Subscriptions Hub)
- **告别扣费糊涂账**：清晰把控所有周期性固定开销（iCloud、流媒体、宽带、房租等），不再出现“什么时候被自动扣费了都不知道”。
- **月均与年化固定成本折算**：无论季付、年付还是周缴，自动统一归一化为「折合月度固定支出」，帮你更理性评估长期数字资产持有成本。
- **自愈式双模记账机制**：
  - **云端定时调度**：绑定 Cloudflare Workers Cron Trigger（每天凌晨自动运行）。
  - **无感自愈入账**：用户只要在任意时间打开账本，后端在响应时会自动对比并补记到期的自动记账订阅，双重保障不落空。
- **手动确认队列**：对于金额可能浮动的订阅（如水电煤、弹性云服务），可配置为「手动确认模式」，到期时在置顶提醒栏中一键核对并点击「立即入账」。

## 🚀 本地开发与体验

### 1. 环境准备
确保本机安装了 Node.js (推荐 v18+ 或 v20+)。

### 2. 安装项目依赖
```bash
cd cf-bookkeeping
npm install
```

### 3. 初始化本地 SQLite 数据库
```bash
npx wrangler d1 execute cf_bookkeeping_db --local --file=./d1/schema.sql
```

### 4. 编译前端并启动本地开发服务
```bash
npm run build
npm run dev:worker
```
- 本地访问地址：**`http://127.0.0.1:8787`**
- 首次访问会自动弹出**「首次安装设置管理员向导」**，设置自定义账号和至少 6 位密码即可开启记账！

## ☁️ 生产环境部署指南 (Cloudflare)

### 步骤 1：登录 Cloudflare 账号
在终端中执行以下命令（会弹出浏览器登录并授权）：
```bash
npx wrangler login
```

### 步骤 2：在云端创建正式的 D1 数据库
```bash
npx wrangler d1 create cf_bookkeeping_db
```
执行成功后，终端会打印出类似如下的配置：
```jsonc
[[d1_databases]]
binding = "DB"
database_name = "cf_bookkeeping_db"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx" // 复制此处的 database_id
```

### 步骤 3：配置 `wrangler.jsonc`
打开项目根目录下的 `wrangler.jsonc` 文件，将上述生成的 `database_id` 替换进去：
```jsonc
"d1_databases": [
  {
    "binding": "DB",
    "database_name": "cf_bookkeeping_db",
    "database_id": "你的真实-database_id"
  }
]
```

### 步骤 4：在云端数据库初始化表结构
```bash
npx wrangler d1 execute cf_bookkeeping_db --remote --file=./d1/schema.sql
```

### 步骤 5：设置生产环境高强度 JWT 密钥 (推荐)
为确保生产安全，可通过安全命令配置独立的 JWT 密钥：
```bash
npx wrangler secret put JWT_SECRET
# 根据终端提示输入一串随机安全字符 (例如: my-super-secret-jwt-key-2026)
```

### 步骤 6：一键打包并部署上线
```bash
npm run deploy
```
部署完成后，终端会输出你的全球免费专属域名（例如 `https://cf-bookkeeping.xxxx.workers.dev`）。

## 🗄️ 数据库模型说明 (Schema)

项目采用基于 SQLite 的 Cloudflare D1 存储，核心表结构如下：

| 表名 | 作用 | 核心字段说明 |
| :--- | :--- | :--- |
| **`users`** | 用户/管理员账号 | 用户 ID、用户名、加盐密码哈希 (PBKDF2)、盐值、昵称 |
| **`accounts`** | 资产账户 | 账户类型 (微信/支付宝/银行卡/现金/信用卡)、初始余额、实时动态余额、颜色与图标 |
| **`categories`**| 收支分类 | 分类名称、类型 (支出/收入)、图标名、排序权重 |
| **`transactions`**| 记账流水 | 交易类型 (支出/收入/转账)、金额 (分)、关联账户、分类、时间、备注、场景、分摊周期、外部单号 |
| **`items`** | 大件与心愿单 | 物品名称、分类、买入价、购买日、状态 (服役/闲置/损坏/二手/心愿单)、质保日、位置、冷静期天数 |
| **`item_expenses`**| 物品追加费用 | 关联物品 ID、支出金额 (分)、支出说明 (如换电池/买配件)、日期 |
| **`auto_rules`** | 自动分类与场景规则 | 匹配模式、关键词、目标账户/分类、目标消费场景、优先级、启用状态 |
| **`api_tokens`** | 快捷指令长期令牌 | 令牌 Hash、安全前缀、关联用户、最近调用时间 |
| **`shortcuts`** | 快捷指令版本与分发 | 快捷指令 ID、版本号、签名状态、分发模式、官方/个人 iCloud 链接、下载计数 |
| **`prepaid_cards`**| 会员充值卡与次卡 | 卡名、类型(储值/计次)、商家、面值、实付、赠送、当前剩余、折算成本、有效期、状态 |
| **`prepaid_card_logs`**| 充值卡操作与核销日志 | 关联卡 ID、类型(充值/核销/校准/退款)、变动值、实付折算金额、关联流水 ID、时间、备注 |
| **`subscriptions`** | 周期性订阅与固定开销 | 订阅名称、周期类型(月/年/周/季)、扣费金额、付款账户、分类、下次扣款日、自动入账开关、状态 |
| **`user_ai_configs`**| AI 大模型与识图配置 | 提供方模式 (Workers AI / 自定义)、自定义端点、API Key、模型名称、启用状态 |

## ❓ 常见问题 FAQ

#### Q1: 重新打包部署后浏览器显示白屏或打不开？
- **原因**：这是因为浏览器缓存了旧版本的 HTML，试图加载旧的 JS 文件哈希。
- **解决**：在网页上按 **`Ctrl + F5`**（Mac 上按 **`Cmd + Shift + R`**）**强制刷新**浏览器即可。本项目后端已配置 HTML 不缓存策略以降低此情况发生。

#### Q2: 忘记管理员登录密码怎么办？
因为数据 100% 由你自己掌控，如果你在本地开发忘记了密码，可以直接清空本地表重新配置：
```bash
npx wrangler d1 execute cf_bookkeeping_db --local --command="DELETE FROM users;"
```
刷新页面即可重新触发首次安装向导。如果是远端生产环境，替换命令中的 `--local` 为 `--remote` 即可。

#### Q3: 如何备份或迁移我的数据？
登录系统后，点击导航栏的 **「设置」** 页面，找到 **「数据备份与导出」**，点击 **「全量导出记账数据 (JSON)」** 即可一键下载完整的离线备份文件。
